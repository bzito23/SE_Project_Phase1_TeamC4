# Project Details
## Project Title: Smart Daycare Monitoring System
## Problem Statement:
Every parent is concerned about leaving their children in daycare facilities, whether public or private. Parents often do not receive updates during the day regarding their child’s behavior, activities, meals, or sleep patterns. Additionally, safety can be an issue, especially when a child is picked up by someone without the parent being fully aware at the moment of the departure of the kid.
## Proposed Solution:
We propose a smart system that provides real-time updates to parents about their child’s daily activities, including sleep, meals, and behavior, along with photos. The system will also enhance security by notifying parents immediately when a child is picked up or leaves the premises. A unique safe word system will be implemented to ensure only authorized individuals can pick up the child.
## Project Scope:
- Aim: To improve communication between daycare facilities and parents while ensuring maximum child safety through real-time monitoring and notifications.
- Objectives:
1. Provide real-time updates on children’s activities, sleep, and meals.
2. Allow parents to view daily menus and photos.
3. Implement a notification system for child pickup and absence.
4. Ensure child safety using a secure “safe word” verification system.
## Application Description:
The Smart Daycare Monitoring System is a web/mobile application designed for daycare centers and parents. Caregivers can log daily updates such as activities, meals, and sleep schedules, and upload photos. Parents can access this information in real time through the app. The system also includes safety features such as instant notifications when a child leaves the facility and a secure pickup process using a unique safe word for each child.
